## 2. 우리의 강점 (경쟁사 대비)

| 강점 | 설명 |

## 4. 우선순위별 개선 권장사항

### TIER 1: 즉시 구현 (1-3일, 낮은 노력 / 높은 임팩트)

1. **Featured Post 섹션** — 블로그 상단에 "Editor's Pick" 1-2개 큰 카드
   - `BlogPost`에 `featured: boolean` 추가 또는 슬러그 하드코딩
   - 참고: Levels.fyi "Latest", Glassdoor "The Latest & Greatest"

2. **인기글 섹션** — "Top Reads" 3-5개
   - 수동 큐레이션 (GA 연동 불필요)
   - `popular: boolean` 또는 정적 슬러그 배열

3. **Show More 버튼** — 초기 12개 표시 → "Show all" 클릭 시 전체
   - 스크롤 깊이 감소, 체감 성능 개선
   - 참고: PayScale "Load more" 패턴

### TIER 2: 단기 (1-2주, 중간 노력)

4. **블로그 검색** — 제목/excerpt/keywords 클라이언트 필터링
   - 50개 포스트 → 백엔드 불필요
   - SearchAction JSON-LD 추가 (Google SERP 검색 박스)

5. **카테고리 허브 페이지 (SEO)** — `/blog/category/rankings` 등 5개 URL
   - 고유 meta title/description, BreadcrumbList
   - 집중 키워드 타겟 인덱스 페이지 5개 추가
   - 참고: Glassdoor `/blog/category/career-advice/`

6. **작성자 표시** — "By AIPF Research Team"
   - E-E-A-T 신호 강화 (Google 평가 요소)

### TIER 3: 장기 (3-4주, 높은 노력)

7. **리치 썸네일** — `/api/og` 활용 포스트별 미니 차트 이미지
   - 데이터 시각화 썸네일 = 경쟁사 대비 차별화
8. **뉴스레터** — 이메일 캡처 (Mailchimp 무료 등)
9. **다중 콘텐츠 유형** — 데이터 보고서, 가이드, 인포그래픽

## 5. 핵심 인사이트

- **가장 가까운 비교 대상**: Levels.fyi (68 포스트, 유사 탭 UI) — 우리는 이미 비슷한 수준
- **최대 차별화**: 데이터 기반 자동 생성 콘텐츠 (테이블, 바차트, PPP 분석) — 어떤 경쟁사도 없음
- **가장 큰 갭**: 검색 + Featured + 썸네일 — 5개 경쟁사 전원 보유
- **최고 ROI**: Featured 섹션 + Show More (순수 클라이언트 변경, 인프라 불필요)
